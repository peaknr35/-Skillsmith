# source-to-skill
Converts a paper, article, or book into one or more agent skill folders (SKILL.md + references/ + scripts/).
Core job: turn DESCRIPTIVE claims into PROCEDURAL playbooks. A summary is a failure.
Rules: never invent numbers; every number needs a printed-page cite; label extrapolations; keep source conditions; grade evidence A/B/C.
Stages run in order. Each stage reads only its CONTEXT.md contract + listed inputs. Never load the whole source after stage 01.
Stop at every REVIEW GATE and wait for human approval (write approval to the stage's output/APPROVED file).
Fix bad output by editing _config/, not the generated skill.
