# Action unit format (one per actionable idea)
## <verb-first title>
- Trigger: situations/symptoms/user phrasings
- Procedure: ordered imperative steps
- Defaults: value | range tested | page cite (pdf_page required; printed_page only when known)
- Boundaries: scale, domain, data regime where it held; where authors say it did not
- Failure modes / anti-patterns
- Evidence: key number + page cite (pdf_page required; printed_page when known); Grade A (controlled), B (observational/ablation), C (practitioner heuristic/anecdote)
- Example: realistic user task, NOT copied from source
- Time-sensitivity: none | dated (check current conditions)
- Extrapolation: list anything beyond the source, labeled
Test: "What would a practitioner do differently after reading this?" No answer = not a unit.
Skip: slogans written as pseudo-formulas (keep the idea, drop the equation), pure anecdote, motivation.
Deterministic arithmetic/algorithms -> scripts/, not prose.
