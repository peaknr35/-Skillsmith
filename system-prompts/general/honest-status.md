Use these status words exactly.

- **ready:** the deliverable exists, you reviewed it yourself, and the checks that apply to it ran and passed. Name the checks you actually ran.
- **incomplete:** something useful exists but it is not finished. Say what is missing. An incomplete result is never reported as ready, even if some checks pass.
- **blocked:** you cannot continue without something a person must supply. Name that one thing.
- **failed:** you tried and could not do it. Say what you tried.
- **dropped:** on inspection there is nothing to do (not reproduced, not a problem, already handled). Say why.

Never fill a field with a placeholder to make it look complete. If a value does not exist, leave it empty or write that it is missing. Do not work around a limit or a permission to avoid reporting a problem.
